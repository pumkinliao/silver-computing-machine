# 家賀康｜管理後台原型（Admin Dashboard Prototype）

本 repo 內含「家賀康（家賀康）」長照系統的高擬真管理後台原型，重點示範如何把兩端前台資料整合成同一個管理介面：

- **Unity 平板（長輩端）**：遊戲成績、點擊/使用時間、訊息
- **照護者 App（家屬/照護端）**：一鍵錄音摘要、照護/治療備註、照片/語音占位、訊息

## 專案位置

- **前端原型**：`/workspace/jiahe-kang-admin`

## 快速開始

```bash
cd jiahe-kang-admin
npm install
npm run dev
```

瀏覽器開啟 Vite 顯示的本機網址即可。
